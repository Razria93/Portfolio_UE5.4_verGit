Action·Reaction은 시작·완료·중단 및 Notify 시점에 피드백 요청을 보냅니다. 실행 피드백, 피격 결과, 캐릭터 사망 표현은 각 담당 경로에서 처리하며, World의 카메라 요청은 PlayerFeedback이 로컬 플레이어 조건에 맞게 소비합니다.

Niagara·효과음·머티리얼 표현·카메라 셰이크는 발생 계기와 종료 조건이 다릅니다. PerfectDodge 성공 표현은 리액션 무적 시간과 별도의 수명을 사용합니다.

bool UCPlayerFeedbackComponent::CanCameraShake(const FCameraShakeRequest& InCameraShakeRequest) const
{
	if (!IsValid(OwnerPlayerController_Injected)) return false;
	if (!OwnerPlayerController_Injected->IsLocalController()) return false;
	if (!IsValid(OwnerPlayerController_Injected->PlayerCameraManager)) return false;

	if (!IsValid(InCameraShakeRequest.CameraShakeClass)) return false;

	if (!FMath::IsFinite(InCameraShakeRequest.CameraShakeBaseScale)) return false;
	if (InCameraShakeRequest.CameraShakeBaseScale <= KINDA_SMALL_NUMBER) return false;

	return true;
}

사망·디졸브·적 정리

논리적 사망, 사망 리액션, 디졸브 표현과 최종 제거 시점을 연결합니다.

Health의 사망 상태와 Dead Reaction 실행을 바탕으로 사망 표현을 요청합니다. CharacterFeedback은 요청·시작·완료 상태를 관리하고 실제 캐릭터·무기 디졸브는 Blueprint와 무기 전달 경로가 수행합니다. 적은 해당 종료 조건에 맞춰 정리됩니다.

여기서 다루는 범위는 적 사망과 제거입니다. 디졸브 효과 리소스의 출처와 Blueprint·실행 연동의 구현 범위는 외부 에셋 문서에 구분합니다.

bool UCCharacterFeedbackComponent::RequestDeathPresentation(EDeathPresentationReason InReason)
{
	if (!IsValid(OwnerCharacter_Injected)) return false;
	if (InReason == EDeathPresentationReason::None || InReason == EDeathPresentationReason::Max) return false;

	if (DeathPresentationState != EDeathPresentationRuntimeState::Inactive)
	{
		return true;
	}

	if (!OnDeathPresentationRequested.IsBound()) return false;

	DeathPresentationState = EDeathPresentationRuntimeState::Requested;

	OnDeathPresentationRequested.Broadcast(InReason);
	return true;
}

CombatHUDWidget은 자원·액션 아이콘을 표시합니다. TargetHUDPresenter는 공통 전투 대상의 변경을 받아 마커를 갱신하고, 유효한 대상이 없으면 숨깁니다. 대상 월드 좌표는 화면 좌표로 투영해 표시합니다.

HUD는 전투 상태를 표시하는 소비자이며 실행 판단이나 피해 판정을 수행하지 않습니다. 표시 로직과 외부 폰트·생성 아이콘 리소스의 기여는 구분합니다.

void UCTargetHUDPresenterComponent::SynchronizeTargetState()
{
	const FCombatTargetSnapshot snapshot = IsValid(CombatTargetComponent_Injected) ? CombatTargetComponent_Injected->GetCombatTargetSnapshot() : FCombatTargetSnapshot();
	const bool bHasTarget = IsValid(snapshot.TargetActor);

	SetComponentTickEnabled(bHasTarget && IsValid(TargetHUDWidget));

	if (bHasTarget)
	{
		UpdateTargetMarker();
		return;
	}

	HideTargetMarker();
}

실행·전투·AI·피드백 모듈이 도메인별 사건을 기록합니다. 오버레이는 수집된 실행 결정, 적용 방식, 거절 이유와 현재 Actor 상태·최근 사건을 화면 패널에 표시합니다.

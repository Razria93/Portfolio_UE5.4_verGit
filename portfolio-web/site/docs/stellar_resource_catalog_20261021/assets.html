외부 리소스를 바탕으로 확장한 구현

캐릭터·무기 디졸브

외부 리소스
UE5 Dissolve Edge VFX의 디졸브 경계 효과와 머티리얼 함수를 활용했습니다.
수정·구현
캐릭터·무기용 재질을 구성·수정하고, 캐릭터와 무기 Blueprint의 연출 흐름을 작성했습니다. Blueprint와 C++를 연결해 연출의 시작·진행·종료를 제어합니다.
적용 방식
사망 연출 요청에 따라 Timeline 값을 캐릭터 재질·Niagara·무기 디졸브에 전달하여 연출을 진행합니다.

전투 머티리얼 오버레이

외부 리소스
Ultimate Character VFX의 Fresnel 오버레이 기반 재질을 활용했습니다.
수정·구현
프로젝트용 재질을 수정·조정하고, 메시별 동적 머티리얼 적용, 가중치 변화 및 이전 오버레이 복원 처리를 구현했습니다.
적용 방식
전투 피드백의 실행 시점에 오버레이를 적용하고 변화시킨 뒤 복원합니다. 디졸브 진행값과 오버레이 가중치는 별도로 제어합니다.

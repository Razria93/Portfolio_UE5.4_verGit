442: 
443: ```text
444: 40 / 80 Enemy 모두 MovementMode 1은 CMovementComponent tick count를 줄였지만 Frame / GameThread p95 개선으로 이어지지 않았다.
445: 또한 Alert Spread 중 locomotion representation이 Idle Locomotion으로 남아 표현 품질을 깨뜨린다.
446: 따라서 Mode 1은 현재 조건의 주요 병목 축이 아니며 Runtime LOD 후보에서 제외한다.

449: 따라서 Movement / Nav 최적화는 state refresh tick을 줄이는 방향보다, far / non-combat enemy의 active movement 빈도나 movement intent 자체를 줄이는 방향이 더 타당하다.
450: 
451: 다만 Mode 2는 gameplay state를 크게 바꾸고, Engage 유효 거리 안의 Enemy가 이동 없이 Attack을 시도할 수 있다.
452: 따라서 그대로 Runtime LOD로 적용하기보다, distance / combat relevance 기반으로 movement update interval, path request 빈도, active movement budget, Engage / Attack gate를 함께 조정하는 방식으로 설계한다.
453: ```

321: 다만 GPU p95 감소폭은 제한적이므로, WeaponActor는 GPU 병목보다 actor / component / animation update 비용 축으로 해석한다.
322: 80 Enemy 기준에서도 WeaponActor 제거는 유효한 Object Management 최적화 후보지만, 실제 gameplay 적용은 combat-capable 단계와 weapon dependency를 함께 고려해야 한다.

실제 장면: 피격 반응 후에도 대상 유지

수정 전 비교 정책은 피격 접수 시 TTL을 시작하고, 수정 후는 피격 리액션 종료를 기다립니다. 같은 1초 TTL에서 반응 중 근거가 소진되는 차이를 비교했습니다. 후속 Investigate 회전은 비교 장면에서 제외했습니다.

확인 범위와 별도 정리 수정안

19개 시나리오 통과가 모든 생명주기 정리를 보장하지는 않습니다. 같은 검증에서 공격자 파괴 후 대기 기록이 남는 경계가 별도로 관찰됐습니다.

공격자 종료를 관찰하고 리스너·대기 기록을 독립적으로 해제하는 별도 수정안은 기존 19개와 신규 8개를 합친 27개 시나리오를 통과했습니다. 8명 반복 파괴 후 Pending은 8에서 0으로 감소했습니다.

이 수정안은 검증 당시 원본 프로젝트에 반영하지 않았습니다. 여기서는 TTL 시작·만료 검증과 독립 수정안의 결과를 구분하며, 원본 반영 또는 정상 PIE 연출 검증이 끝났다고 표시하지 않습니다.

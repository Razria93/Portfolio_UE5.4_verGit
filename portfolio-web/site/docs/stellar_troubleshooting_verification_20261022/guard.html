포트폴리오 11–12쪽의 기존 시연은 피해 20인 사례이며, 이 페이지의 별도 PIE 검증은 HP가 5,000에서 4,700으로 감소한 사례입니다. 서로 다른 실행의 피해 수치와 이동 설정을 구분합니다.

GuardOut 시작 0.075830초 후 피격이 들어왔습니다. 정리 전 Runtime=1 / Handlings=1에서 중단 후 Runtime=0이 됐고, 남은 정리 요청이 수락됐습니다. 실제 Hit 몽타주와 HP 5,000→4,700을 확인했습니다.

실제 연속 PIE 기록 · 약 16.4초. 표는 월드 시간이며 영상 시작은 월드 약 10.55초입니다. 피격은 영상 약 11.7초, 다음 GuardIn은 약 12.9초입니다.

이 자동 검사의 Run 420·Sprint 620은 테스트 fixture 설정입니다. 위 실제 PIE의 Run 600과 같은 게임 설정으로 읽지 않도록 구분합니다.

결과를 적용할 수 있는 범위

Overlay 정리만 수행할 때는 가드 의도를 유지하고, 전체 상태 정리에서는 가드·패링 창과 실행 상태를 해제하는 경계도 검사했습니다. 실제 이동 복원은 최초 속도를 무조건 되돌리는 방식이 아니라 갱신된 기본 이동 요청을 따릅니다.

별도 Sprint 단발 설정 사례는 입력이 유지되지 않아 기본 요청이 Run 600으로 바뀌었습니다. 이를 Sprint 키를 유지한 상태의 800 복원 검증으로 확대하지 않습니다.

PIE에서 적 공격은 테스트가 공개 공격 요청 진입점으로 선택했습니다. 자율 BT의 공격 선택이나 수동 PIE와의 이펙트 동등성을 검증한 자료는 아닙니다. 영상 기록은 평균 약 54.73fps, 종료부 readback 누락 1프레임으로 기록됐으며, 제출용 60fps 촬영 품질과 구분합니다.

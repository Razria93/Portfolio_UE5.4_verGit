# Implement CPlayerCharacter movement core and basic locomotion AnimBP

## Title

✨ feat: implement movement core and basic locomotion AnimBP (#6, #7)

## Summary

- This PR implements the **character movement** (WASD + jump) and sets up a **basic locomotion AnimBP**

- It also Fixes pose distortion caused by retargeting Mannequin animations directly to the Quinn skeleton

---

## Completed Tasks

### 1. Movement / Jump Logic

- Implemented movement logics:
    
    - `CPlayerController` receives move axis input
        
    - Delegates to `CPlayerCharacter` movement handles
      
    - Delegates to `CharacterMovementComponent` OnMoveForward and OnMoveRight
        
    - `CharacterMovementComponent` normalizes input, validates it, and applies movement
        
- Implemented jump:
        
    - `CPlayerController` receives jump action input
    
    - Binds `CPlayerCharacter` jump handlers to `Jump` / `StopJumping`
        
    - `CPlayerCharacter` delegates to `ACharacter` jump API, and `CharacterMovementComponent` drives in-air movement
 

---

### 2. Locomotion AnimBP

- Selected temporary Unarmed **Idle / Walk / Run** and 
  Unarmed **Jump Start / Jump Loop / Jump End** animations for Quinn
    
- Created a speed-based locomotion **BlendSpace** for grounded movement

- Implement **AnimBP**:

    - Grounded state machine (Idle / Move)
    
    - Air state (Jump Start → Jump Loop → Jump End → back to Idle / Move)
    
    - Uses `Speed` for BlendSpace and `bIsInAir` for ground/air transitions
    
- From `UCMovementComponent`, updates:

    - Current `Speed`, `Direction`

    - `IsFalling`


---

### 3. Animation Retargeting Fix (Mannequin → Quinn)

- Issue : #7 

- Found and fixed the pose distortion problem when using Mannequin animations on Quinn

- Imported only the needed Mannequin base assets from the UE5.0 project:

    - `SK_Mannequin`, `SK_Mannequin_Skeleton`, `SK_Mannequin_PhysicsAsset`

- Set up a basic **IK Rig + IK Retargeter** setup:

    - `IK_AutoGeneratedSource` (Mannequin)
    
    - `IK_AutoGeneratedTarget` (Quinn)
    
    - `RTG_AutoGenerated` (Retargeter)

- Retargeted locomotion animations to Quinn and replaced the broken ones

## Notes

- Movement and animation flow are now clearly separated:

    - **Controller**: reads player input and sends it to the character

    - **Character**: decides move / jump intent and forwards it to the movement component

    - **MovementComponent**: checks if move / jump is allowed and applies movement

    - **AnimInstance**: uses `Speed`, `Direction`, and `bIsInAir` to drive locomotion and jump states

- Animation can now be safely retargeted, and this setup will be reused for after animations

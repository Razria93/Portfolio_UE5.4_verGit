## 1. 증상

기존 캐릭터보다 체구가 작은 Celeste로 리타게팅할 때 가슴과 명치 사이가 눌려 보였다. 새 메시를 교체하는 것만으로 기존 자세와 전투 표현이 유지되지 않았다.

## 2. 기존 가정과 제약

같은 Skeleton 기반 변형은 애니메이션 재사용 후보지만 메시 조립과 AnimBP 연결까지 확인해야 한다. 전체 애니메이션에 하나의 보정값이 적합하다고 가정하지 않는다.

## 3. 대안 검토와 결정

당시 세션 A:122에서 Spine Rotation Alpha 조정을 제안했고, A:129에서 사용자가 0.7 적용 후 느낌이 괜찮다고 확인했다. 본별 보정과 Additive Layer Track도 논의했지만 실제 키 저장 완료 근거는 확보하지 못했다.

## 4. 구현·에셋 변경

`a6e79e34`의 캐릭터·애니메이션 도입 결과가 `13299da5`의 최종 Content 구조로 이주됐다. 현재 `Content/01_Character/Retager/RTG_AutoGenerated.uasset`, IK source/target, StellarGirlCeleste와 Stellar Montage가 존재한다. Player Blueprint 후속 검증 변경은 `62378b3f`에 포함됐다.

## 5. 검증 결과와 한계

당시 특정 조정의 시각 개선과 현재 통합 후 사용자 PIE 정상 확인을 확보했다. 현재 Retargeter의 최종 Alpha·chain·pose 설정 및 전체 export 결과는 이번 문서 작업에서 에디터로 재검사하지 않았다.

## 6. 추가 확인

현재 설정 화면 한 장으로 당시 0.7 조정이 최종본에 남았는지 확인하면 된다. Additive 보정을 실제 저장했다면 해당 본·애니메이션만 추가 확인한다.

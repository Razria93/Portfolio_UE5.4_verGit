# Work Journal Notes

이 폴더는 브랜치 작업 중 구조 결정이 바뀌는 지점과 논의 흐름을 기록한다.

작업일지는 매일 기록하는 로그가 아니라, 하나의 논점에서 출발해 설계 방향이 바뀌거나 책임 경계가 확정되는 단위로 작성한다.

권장 형식:

- Context: 왜 이 논점이 생겼는가
- Options: 검토한 선택지
- Discussion: 장단점과 논의 과정
- Decision: 최종 결정
- Reason: 그 결정을 선택한 이유
- Follow-up: 다음 작업에 넘길 내용

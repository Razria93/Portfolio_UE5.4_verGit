5. 판정과 책임 구조

- FDamageSpec:
  공격별 가드·패링·회피 가능 여부를 표현해.
  기존 공격의 기본 동작은 유지해.

- DefenseComponent:
  일반 회피 무적 구간, 저스트 판정 구간 및 성공 소비 상태를 관리해.

- CombatSignalTarget:
  피해 적용 전에 방어 결과를 확정해.
  일반 회피 성공과 저스트 회피 성공을 구분해.
  후속 피해 계산이 이미 확정된 방어 결과를 덮어쓰지 않도록 해.

- Action_Dodge:
  입력으로 시작하는 일반 회피 행동과 허용된 개입 규칙을 담당해.

- Reaction_PerfectDodge:
  성공 시 자동으로 시작되는 동작과 실행 중 무적을 담당해.

- CounterRush:
  반격 기회와 추가 입력을 조건으로 실행되는 별도 액션으로 구성해.

- Feedback:
  붉은 몸 효과, 화면 효과, 슬로우 및 러시 연출을 담당해.
  방어 판정과 게임플레이 이동 책임을 넣지 마.

- HUD:
  실제 실행 상태와 반격 가능 여부를 표시해.
  HUD 조회만으로 기회 소비나 실행이 발생하면 안 돼.

반격 기회 데이터의 소유 위치는 기존 책임 구조를 조사한 뒤 확정해.
불필요한 범용 프레임워크를 만들지 마.
필드·API·섹션 배치 및 Action/Reaction의 구조적 대칭성을 존중해.

6. 반격 기회와 카운터 러시

- 저스트 성공을 발생시킨 적을 반격 대상으로 기록해.
- 현재 락온 대상이 바뀌었다고 반격 대상을 임의로 바꾸지 마.
- 성공 리액션의 지정된 연결 구간부터 추가 입력을 허용해.
- 리액션 종료 후 짧은 유예 시간도 설정할 수 있도록 해.
- 유예 시간은 리액션 종료부터 계산하고 시간 기준을 명확히 해.
- 실행 시 대상 생존·거리·자신의 상태와 실행 가능 여부를 다시 검사해.
- 조회나 입력 접수만으로 기회를 소비하지 마.
- 실제 시작 성립 시 한 번만 소비하고, 시작 실패·즉시 완료·재진입을 처리해.
- 사망·초기화·EndPlay 및 대상 소멸 등의 기회 정리 정책을 명시해.
- 기존 공격 페이싱을 활용하되 돌진 중 무제한 타깃 추적은 하지 마.
- 벽 통과나 대상과의 강제 겹침을 일으키는 위치 보정은 하지 마.
- PerfectDodge의 무적을 CounterRush에 자동 상속하지 마.
- 러시에 별도 보호 구간이 필요하다면 이유와 정책을 제안하고 확인받아.

7. 연출과 시간 관리

다음 항목의 생명주기를 분리해.

- PerfectDodge 실행 중 무적.
- 저스트 성공 슬로우.
- 붉은 몸 효과.
- 로컬 플레이어 화면의 주변부 어두워짐.
- 반격 입력 기회.
- CounterRush 접근·타격 효과.

저스트 성공이 확정된 시점에 짧은 슬로우를 시작하도록 해.
배율과 지속 시간은 튜닝 가능하게 하되 임시값임을 명시해.
슬로우 유지 시간은 실시간 기준을 우선 검토해.
기존 HitStop과 같은 관리 경로에서 중첩·복원을 처리하고,
한 효과의 종료가 다른 효과의 시간 배율을 잘못 복원하지 않도록 해.

회피 판정 구간은 실제 실행·애니메이션 진행과 연결해.
시작이 거절되거나 예약됐는데 무적부터 생기면 안 돼.
Notify End에만 의존하지 말고 중단·교체·사망에서도 정리를 보장해.

8. 안정성

- Hit를 먼저 적용한 뒤 저스트 회피로 되돌리는 구조는 사용하지 마.
- 성공 리액션 시작 실패 때문에 이미 피한 공격의 피해를 소급 적용하지 마.
- 시작 실패 시 무적·슬로우·반격 기회가 잘못 남지 않도록 정책을 정리해.
- 공격 접촉을 받아 판정할 수 있도록 유지해.
  무적을 구현하려고 충돌 자체를 꺼서 저스트 판정이 사라지게 하지 마.
- 이번에는 접촉 기반 판정을 사용하고, 별도 근접 회피 감지 영역은 추가하지 마.
- 동일 공격의 여러 충돌체로 성공이 중복 발생하지 않도록 해.
- 이전 실행의 늦은 Notify나 정리 요청이 새 실행 상태를 제거하지 않도록 해.
- 일반 회피 정리가 새 PerfectDodge 무적을 제거하지 않도록 해.
- 처형의 외부 피해 정책 등 기존 특수 규칙을 회피 판정으로 덮어쓰지 마.
- 일반 피격 Feedback이 회피 성공에도 잘못 재생되지 않도록 해.
- 조회·디버그 데이터가 게임플레이 상태를 변경하면 안 돼.

  실제 BP·몽타주·Root Motion·Notify·입력 설정 조사.

  피해 판정·개입·무적·시간 배율의 생명주기 위험 조사.
- 구현 후 독립 리뷰:
  중복 성공, 무적 누수, 기회 소비, 오래된 콜백,

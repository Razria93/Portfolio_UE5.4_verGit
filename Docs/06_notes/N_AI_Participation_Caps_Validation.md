# AI 참여자 재선정 복구와 보류된 상한 비교 검증

## 현재 범위 — 원래 상한의 C1 복구만 유지

2026-10-23 최종 범위를 C1 재선정 복구와 관련 문서로 좁혔다. 기본 상한과 도움말은 main의 `2 / 3 / 5 / 6 / 12`를 유지한다. C2 축소 후보 `1 / 2 / 3 / 1 / 1`은 복원 가능한 패치·원문·해시로 별도 보존하고 이번 커밋/PR 대상에서 제외했다. 아래 비교·실패 기록은 당시 조건의 역사적 근거이며 현재 기본값을 뜻하지 않는다.

현재 제품 소스·테스트 5파일은 실제 빌드·106개 테스트·에셋 검사·PIE를 통과한 C1 경계와 SHA-256이 모두 같다. 테스트의 명시적 후보 CVar 조건도 동일성 유지를 위해 그대로 두며 제품 기본값 축소를 포함하는 것은 아니다. 이번 범위 정리에서는 추가 군중 실험·PIE·자동 테스트를 실행하지 않았다. 빌드 산출물은 C1 소스에 맞추는 기본 증분 빌드만 별도로 기록한다. 이는 범위 정리 당시의 검증 기록이다. 게시용 구성은 C1 복구·테스트와 C3 문서이며 C2는 제외한다. 실제 커밋·게시 상태는 해당 브랜치와 PR을 기준으로 확인한다.

## 초기 비교의 목적과 상태

## 실제 BT·PIE 조건

SciFiMap의 렌더링된 InProcess PIE, 고정 60Hz 게임 시간, 실제 BP_CPlayer_Stellar와 BP_CEnemy 및 BT_Default 계열을 사용했다. 동일 중심 위치에서 반경 300cm에 적을 배치했다. 적 1명 대조군 1회, 적 12명 조건 2회를 각 버전에서 실행했다. 초기 배치는 같지만 액터 정렬·충돌·BT 실행의 결과까지 결정론적이라고 보장하지 않는다.

자연 시야 획득·BT 이동·콤보 공격을 관측했다. Extra 비교는 공개 ReportHitReactiveEvidence API로 통제된 근거를 넣었으며 실제 플레이어 명중으로 근거를 생성했다고 주장하지 않는다. 사망은 HealthComponent 피해 API로 유발했고 중단은 시스템 취소 API로 실행했다. 모든 액터 배치와 관찰 도구는 일시적이며 맵은 저장하지 않았다.

## 2026-10-23 후속: 재획득 정체의 상한·충돌 분리

G3-T1 로컬 분리본에서 수행했으며 이 원인 분리 기록 작성 당시에는 미커밋·PR 미게시 상태였다. 제품의 참여 상한과 배정 로직을 추가 수정하지 않았다. 임시 진단 소스·헤더·의존성은 제거·복원했다.

동일 진단 바이너리에서 기준 `2/3/5/6/12`와 후보 `1/2/3/1/1`을 런타임으로 바꿨다. 원래 순서는 각 조건에서 군중 2회 재실행했고 양쪽 모두 재획득 후 공격했다. 이는 이전 후보의 정체 기록을 취소하지 않는다. 시작 배치가 같아도 상한에 따라 재획득 전 배치가 달라진다.

이전 실패 CSV의 생존 적 11명 XY를 사용한 별도 통제 실험은 네 조건을 각 3회 실행했다. 당시 높이·방향·BT 내부 상태가 저장되지 않았으므로, 현재 바닥 높이와 이전 sight 여부에 맞춘 방향으로 재구성했다. 같은 공통 워밍업 후 위치·방향을 맞추고 이동·액션·수색·perception을 정리해 BT를 재시작했다. 역사적 월드를 완전히 복원한 실험은 아니다.

직접 원인은 재구성한 조건의 동적 캐릭터 충돌이며, 상한 1명은 막힌 담당자에 의존하는 결과를 만들었다. 다섯 상한의 개별 기여까지 분리한 것은 아니다. SortCandidates/PreserveCommittedRole에는 경로의 Blocked 결과를 이용한 교체 조건이 없고, 공격 거리 밖에서는 UpdateEngageContext가 공격을 허용하지 않는다. 후보 채택은 보류하고, 막힌 Engage 담당자 교체 또는 비참여 적 양보를 독립 수정 범위로 검토한다. 진단용 충돌 무시를 제품 해결책으로 채택하지 않는다.

추가 실패 기록: 기준 원래 순서 R2의 TTL 26초 시점 Extra=0 검사가 실패했다. 직전 25.5초에는 hit evidence=0, assignment lock=1인 Extra가 남았다. 이후 시야 상실·사망 정리는 통과했다. 26초 또는 TTL+3초는 일반적인 최장 해제 기한이 아니다. 기존 성공 기록은 해당 당시 관측으로만 유지한다.

최종 임시 도구 제거 상태의 기본 Unity 빌드와 104개 자동 테스트는 실패 0이며 기존 경고 포함 성공 2건을 유지했다. 에셋 1,440개는 기준 해시와 같다. 임시 비교 도구의 최초 지역 변수 중복 컴파일 실패는 수정 후 재빌드했으며 제품 코드 오류로 분류하지 않는다.

120/200ms 지연의 Stellar 첫 타 빗나감, 기존 패링 실패·조건별 소수 반복·단차 직접 횡단·트레일 지연 종료 미검증은 그대로다. 이번에는 해당 지연·패링 실험을 재실행하지 않았다. 고정 game delta/통제 배치의 각 3회 결과를 장시간 안정성·발생 확률·다른 지형·다중 표적·네트워크·Shipping/Cook 검증으로 확대하지 않는다. 실제 PIE 스크린샷·CSV·이벤트 로그를 확인했고 연속 영상은 만들지 않았다.


## 2026-10-23 수정: 반복 Blocked 참여자 재선정

### 변경 범위와 계약

G3-T1 분리본에만 경로 실패 복구를 추가했다. 참여 상한 기본값 `1/2/3/1/1`과 비교 기준 `2/3/5/6/12`는 유지한다. CAIController는 실제 RequestMove의 ID·표적·AssignmentRevision을 저장하고, 해당 요청의 native 완료 결과만 subsystem에 전달한다. 완료 콜백 안에서 BT를 바꾸지 않고 다음 allocator rebuild에서 반영한다.

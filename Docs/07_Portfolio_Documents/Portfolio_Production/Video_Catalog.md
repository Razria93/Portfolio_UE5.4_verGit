## 12 · TTL: 최신 38.8초와 기존 공개 37초

최신 파일은 `stellar_ttl_portfolio_20261021/render/stellar_12_ttl_portfolio_v2_1440p60.mp4`입니다. 10월 1일 보존 환경의 승인된 재촬영을 사용하며, 전후 비교 → TTL 진단 → 처리 도식 → 종료 후 상태 → 정리 재생으로 구성했습니다. 실제 월드 촬영과 별도 진단 HUD 캡처를 구분해 사용했습니다.

- 최신 파일: 38.8초 / 2560×1440 / 60fps 출력 / 2,328프레임 / SHA-256 `227e9b318dd869ede127517b54ab59fcece4f61bf03f415e703f1a520ecd64a8`.
- 기존 공개 URL: 플레이어 0:37 표시 확인. 최신본으로 재사용하지 않습니다.
- 제작 당시 검수 기록: 전체 디코딩, 주요 8장면·7경계 표본, PPT 해당 페이지 화면 확인. 실제 청취·전체 연속 재생·PPT 내부 클릭은 미수행.
- 원본 촬영은 가변 프레임이며 60fps는 최종 출력 규격입니다. 현재 코드의 모든 동작을 증명하는 영상이 아닙니다.

최신 로컬 `Project_Stellar_TTL_포트폴리오반영_v2.pptx`는 22페이지이며 5쪽 목록과 TTL 9–10쪽이 갱신됐습니다. 영상 링크는 배포 묶음 내부 상대 경로입니다. 공개 PPT/PDF 주소와 최신 영상 주소가 확보되기 전까지 외부 방문자용 다운로드·재생 링크로 제시하지 않습니다. 웹의 23페이지 HTML은 이 변경을 자동으로 반영하지 않습니다.

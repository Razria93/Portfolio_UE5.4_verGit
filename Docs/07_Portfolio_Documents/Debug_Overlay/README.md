# Debug Overlay Evidence Workspace

## Purpose

This workspace tracks the debug overlay work used as evidence for resume, portfolio, and technical documentation.

The overlay is not a production HUD. It is a development-only visual aid for submission videos and technical evidence.

## Folder Tree

- `01_Planning`
  - fixed scope, implementation plan, risk notes
- `02_Operation`
  - session rules, branch policy, verification flow
- `03_Evidence_Map`
  - runtime values, source files, confidence level
- `04_Capture_Presets`
  - video presets and overlay layouts

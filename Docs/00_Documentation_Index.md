## 참조 원칙

- 문서 본문에서는 파일명 전체보다 `D15`, `B09`, `P17`, `S23`, `PF03` 같은 문서 ID를 우선 사용한다.
- 실제 파일 경로, 문서 목적, 관련 문서는 각 문서 유형별 Index에서 확인한다.
- GitHub PR / Issue 번호는 명확히 확인된 경우에만 각 문서 유형별 Index에 기록한다.
- 문서 파일명이 바뀌면 해당 문서 유형별 Index를 먼저 갱신한다.

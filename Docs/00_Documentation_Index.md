# Documentation Index

이 문서는 UE5 Portfolio 문서군의 상위 라우터다.
개별 문서 목록은 각 문서군 내부의 `00_*_Index.md`에서 관리한다.

---

## 문서 ID 규칙

```text
Dxx  -> Issue Checklist
Bxx  -> Bug Report
Pxx  -> Pull Request
Sxx  -> System Architecture
PFxx -> Portfolio Document
```

---

## 문서군 인덱스

| 문서군 | 역할 | 인덱스 |
| --- | --- | --- |
| Issue Checklist | 작업 전 목표 / 체크리스트 / 검증 기준 기록 | `Docs/99_Legacy/Issue_CheckList/00_Issue_Checklist_Index.md` |
| Bug Report | 재현 가능한 문제, 원인, 수정 기준 기록 | `Docs/02_Bug_Report/00_Bug_Report_Index.md` |
| Pull Request | 브랜치별 변경 요약, 범위, 검증 결과 기록 | `Docs/04_Pull_Request/00_Pull_Request_Index.md` |
| System Architecture | 시스템 구조, 책임 경계, 설계 기록 관리 | `Docs/05_System_Architecture/00_System_Architecture_Index.md` |
| Portfolio Document | 외부 설명용 포트폴리오 문서 관리 | `Docs/07_Portfolio_Documents/00_Portfolio_Document_Index.md` |

## 참조 원칙

- 문서 본문에서는 파일명 전체보다 `D15`, `B09`, `P17`, `S23`, `PF03` 같은 문서 ID를 우선 사용한다.
- 실제 파일 경로, 문서 목적, 관련 문서는 각 문서군 인덱스에서 확인한다.
- GitHub PR / Issue 번호는 명확히 확인된 경우에만 각 문서군 인덱스에 기록한다.
- 문서 파일명이 바뀌면 해당 문서군 인덱스를 먼저 갱신한다.

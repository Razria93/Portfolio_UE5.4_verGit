## 환경

- 엔진: Unreal Engine 5.4  
- 소스 프로젝트: **UE5.0 (UE4 Mannequin 스켈레톤/메시 사용)**  
- 타겟 프로젝트: UE5.4 (**UE5 Quinn 스켈레톤/메시 사용**)

---

## 재현 절차

1. UE5.0 버전에서 UE5.4버전으로 자산 이주가 불가능하여 애니메이션 파일들을 복사해서 가져와야 하는 상황.
2. UE4 Mannequin 스켈레톤을 사용하던 UE5.0 프로젝트에서 애니메이션 `.uasset` 파일들을 UE5.4 프로젝트로 복사.
3. UE5.4에서 해당 애니메이션의 스켈레톤을 **Mannequin → Quinn** 으로 직접 변경한다.
4. Quinn 메시에서 애니메이션을 재생하면  
   팔/다리 방향이 틀어지거나 길이가 맞지 않는 심한 변형이 발생한다.

---

## 예상 동작 vs 실제 동작

**예상 동작**  
- Quinn 메시에서도 원본 Mannequin 애니메이션과 동일한 품질로 재생되어야 한다.

**실제 동작**  
- 스켈레톤 구조와 비율 차이 때문에 포즈가 크게 비틀리고 팔/다리 길이가 이상하게 재생됨.

---

## 원인 분석 (Root Cause)

- 애니메이션은 **UE4 Mannequin 스켈레톤** 기준으로 제작된 데이터였음.
- 이를 UE5.4로 가져온 뒤, **올바른 리타게팅 없이** 스켈레톤을 Quinn으로 강제로 교체함.
- Mannequin과 Quinn은 **본 구조 / 본 비율 / 본 네이밍**이 다르므로  
  스켈레톤 교체만으로는 포즈 정보를 보존할 수 없음.

---

## 해결 방법 (Fix)

1. UE5.0 프로젝트에서 Mannequin 관련 에셋들을 가져옴:
   - `SK_Mannequin`
   - `SK_Mannequin_Skeleton`
   - `SK_Mannequin_PhysicsAsset`

2. 복사해 온 애니메이션들을 다시 Mannequin 스켈레톤에 연결하여 정상 재생되는 것을 확인함.

3. Mannequin → Quinn 리타게팅 파이프라인 구성:
   - `IK_AutoGeneratedSource`
   - `IK_AutoGeneratedTarget`
   - `RTG_AutoGenerated` (IK Retargeter)

4. Retargeter를 사용해 Quinn 전용 애니메이션을 새로 생성하고,  
   기존(깨진) 애니메이션을 새 버전으로 교체함.

---

## 검증 (Verification)

- Retarget된 애니메이션을 Quinn AnimBP에 연결하여 확인:
  - Idle / Walk / Run 모두 정상 포즈 유지  
  - 팔/다리 길이 및 방향 문제 해결  
  - 비틀림 없음

---

## 비고 (Notes)

- 서로 다른 스켈레톤 간에는 **절대 스켈레톤을 직접 재할당하면 안 됨**.  
- 반드시 **IK Rig + IK Retargeter 기반 리타게팅**을 사용해야 함.

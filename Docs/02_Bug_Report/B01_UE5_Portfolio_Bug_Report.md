# UE5 Portfolio Bug Report

## 제목

**B01: Mannequin 애니메이션을 Quinn 스켈레톤에 적용했을 때 발생하는 포즈 손상 문제**

## 날짜

**2025.12.04**

## 상태

- [x] **완료**

---

## 브랜치

- `feature/character-move-core`

---

## 요약

- UE4 Mannequin 기준 애니메이션을 UE5 Quinn 스켈레톤에 직접 연결하면서 발생한 포즈 손상 문제를, IK Rig / IK Retargeter 기반 리타게팅으로 해결했다.

---

## 영향 범위

- Quinn 캐릭터 이동 애니메이션 품질

- UE4 Mannequin 애니메이션을 UE5 Quinn 스켈레톤으로 옮기는 리타게팅 흐름

---

## 환경

- 엔진: Unreal Engine 5.4

- 소스 프로젝트: UE5.0 (UE4 Mannequin 스켈레톤/메시 사용)

- 타겟 프로젝트: UE5.4 (UE5 Quinn 스켈레톤/메시 사용)

---

## 발생 조건

- UE5.0 프로젝트의 Mannequin 애니메이션 `.uasset`을 UE5.4 프로젝트로 복사한 뒤 Quinn 스켈레톤에 직접 재할당할 때 발생한다.

---

## 재현 방법

1. UE5.0 버전에서 UE5.4 버전으로 자산 이주가 불가능하여 애니메이션 파일들을 복사해서 가져와야 하는 상황이었다.

2. UE4 Mannequin 스켈레톤을 사용하던 UE5.0 프로젝트에서 애니메이션 `.uasset` 파일들을 UE5.4 프로젝트로 복사한다.

3. UE5.4에서 해당 애니메이션의 스켈레톤을 **Mannequin -> Quinn** 으로 직접 재할당한다.

4. Quinn 메시에서 애니메이션을 재생하면 팔/다리 방향이 틀어지거나 길이가 맞지 않는 심한 변형이 발생한다.

---

## 기대 결과 vs 실제 결과

**기대 결과**

- Quinn 메시에서도 원본 Mannequin 애니메이션과 동일한 품질로 재생되어야 한다.

**실제 결과**

- 스켈레톤 구조와 비율 차이 때문에 포즈가 크게 비틀리고 팔/다리 길이가 이상하게 재생되었다.

---

## 원인

- 애니메이션은 **UE4 Mannequin 스켈레톤** 기준으로 제작된 데이터였다.

- 이를 UE5.4로 가져온 뒤, **올바른 리타게팅 없이** 스켈레톤을 Quinn으로 강제로 교체했다.

- Mannequin과 Quinn은 **본 구조 / 본 비율 / 본 네이밍**이 다르므로 스켈레톤 교체만으로는 포즈 정보를 보존할 수 없다.

---

## 수정

1. UE5.0 프로젝트에서 Mannequin 관련 에셋들을 복사:
	- `SK_Mannequin`
	- `SK_Mannequin_Skeleton`
	- `SK_Mannequin_PhysicsAsset`

2. 복사해 온 애니메이션들을 다시 Mannequin 스켈레톤에 연결하여 정상 재생되는 것을 확인했다.

3. Mannequin → Quinn 리타게팅 파이프라인 구성:
	- `IK_AutoGeneratedSource`
	- `IK_AutoGeneratedTarget`
	- `RTG_AutoGenerated` (IK Retargeter)

4. Retargeter를 사용해 Quinn 전용 애니메이션을 새로 생성하고, 기존(손상된) 애니메이션을 새 버전으로 교체했다.

---

## 수정 기준

- 서로 다른 스켈레톤 간 애니메이션은 직접 재할당하지 않고 IK Rig / IK Retargeter 기반으로 변환한다.

- 원본 Mannequin 스켈레톤에서 정상 재생되는 것을 먼저 확인한 뒤 Quinn 전용 애니메이션을 생성한다.

---

## 검증 결과

- Retarget된 애니메이션을 Quinn AnimBP에 연결하여 재생 상태를 확인했다.

- Idle / Walk / Run 모두 정상 포즈를 유지하는 것을 확인했다.

- 팔/다리 길이 및 방향 문제가 해결된 것을 확인했다.

- 포즈 손상이 재현되지 않는 것을 확인했다.

---

## 회귀 방지 기준

- Retarget된 Idle / Walk / Run 애니메이션에서 포즈 손상이 없어야 한다.

- Quinn AnimBP에 연결한 뒤 팔 / 다리 방향과 길이가 정상으로 유지되어야 한다.

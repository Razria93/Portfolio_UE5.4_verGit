**M01-B01: Fix distorted poses after assigning Mannequin animations to Quinn skeleton**

## Summary

- Fixed animation pose distortion when transferring Mannequin animations from UE5.0 to UE5.4 (Quinn)


---

## Environment

- Engine: Unreal Engine 5.4  
  
- Source Project: UE5.0 using **UE4 Mannequin** skeleton/mesh  
  
- Target Project: UE5.4 using **UE5 Quinn** skeleton/mesh


---

## Steps to Reproduce

1. UE5.0 → UE5.4 project migration was not supported, so animation assets had to be copied manually
	   
2. Copy animation `.uasset` files from the UE5.0 project into the UE5.4 project
	   
3. In UE5.4, change the animation skeleton from **Mannequin** to **Quinn**
	   
4. Play the animation on the Quinn mesh
	   
5. The arms and legs become heavily distorted


---

## Expected vs Actual

**Expected**  
- The animations should play on the Quinn character with the same pose quality as on the Mannequin

**Actual**  
- Due to differences in the skeleton structure and proportions, the pose is significantly distorted


---

## Root Cause

- The animations were originally authored for the UE4 Mannequin skeleton
  
- They were brought into UE5.4 and forcefully reassigned to the Quinn skeleton without proper retargeting
  
- A simple skeleton swap cannot preserve the original pose data due to differences in the Mannequin and Quinn's bone hierarchy, naming conventions, and proportions


---

## Fix

1. Imported the following Mannequin assets from the UE5.0 project:
	
	- `SK_Mannequin`
	     
	- `SK_Mannequin_Skeleton`
	     
	- `SK_Mannequin_PhysicsAsset`
	
2. Reassigned the copied animations back to the Mannequin skeleton and confirmed they played correctly
	
3. Set up a proper retargeting workflow (Mannequin → Quinn):
	
	- `IK_AutoGeneratedSource`
     
	- `IK_AutoGeneratedTarget`
     
	- `RTG_AutoGenerated` (IK Retargeter)
	
4. Retargeted the animations to Quinn and replaced the previously broken versions


---

## Verification

- Connected the retargeted animations to Quinn’s AnimBP and verified:

- Idle / Walk / Run animations play correctly  

- Limb rotation and length are consistent  

- No remaining distortion


---

## Notes

- Never directly assign animations to a skeleton with a different hierarchy
  
- Always use **IK Rig + IK Retargeter** when transferring animations from Mannequin to Quinn or other skeletons

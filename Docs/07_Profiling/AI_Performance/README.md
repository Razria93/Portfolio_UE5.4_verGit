# AI Performance 프로파일링

이 폴더는 AI performance 프로파일링 계획, 측정 노트, evidence manifest를 보관한다. 공통 CSV 분석 기준은 `../CSV_Analysis_Guide.md`를 따른다.

raw CSV / log 캡처는 repository에서 제외한다. source capture 식별은 `CSV_Evidence_Manifest.md`를 사용하고, 해석된 결과는 각 Runtime LOD 문서를 기준으로 확인한다.

## 문서

| 파일 | 목적 |
| --- | --- |
| `CSV_Evidence_Manifest.md` | source capture ID / case manifest |
| `Runtime_LOD/` | Runtime LOD 프로파일링 계획과 결과 노트 |

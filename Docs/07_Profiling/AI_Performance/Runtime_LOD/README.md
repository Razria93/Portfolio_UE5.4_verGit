# Runtime LOD 프로파일링

이 폴더는 Runtime LOD 프로파일링 계획, 결과 노트, 후속 분석을 보관한다.

raw CSV / log 파일은 이 폴더에 저장하지 않는다. 각 측정 노트는 다음 항목을 기록한다.

- 측정 조건
- 대표 source capture ID
- p95 중심 결과 표
- 해석과 후속 판단
